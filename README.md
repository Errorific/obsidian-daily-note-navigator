# Obsidian Daily Note Navigator

An Obsidian community plugin for navigating daily and periodic notes.

Obsidian's built-in daily notes (and the Periodic Notes community plugin) cover
creating and opening notes for a given date, but quick navigation between
existing periodic notes -- daily, weekly, monthly, quarterly, yearly -- is more
manual than it needs to be. This plugin aims to make moving through that
calendar of notes fast and frictionless.

The plugin is in early development. Concrete features and behavior are being
designed in [`docs/design/`](docs/design/); decisions and their rationale live
in [`docs/decisions/`](docs/decisions/).
